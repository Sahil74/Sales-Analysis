# Sales Analysis Dashboard — Excel

## About the Project

I created this project in Excel to explore sales performance across different states, product categories and months. The dataset contains 337 rows and 8 columns, including units sold, revenue, cost and profit in USD.

I wanted to make the data easier to understand by turning it into charts and an interactive dashboard rather than just looking at rows of numbers.

## What I Analysed

* **Monthly Revenue:** Compared the monthly revenue trends for Hoodies and T-shirts across 2023 and 2024.
* **Units Sold:** Compared the number of units sold for each product category by year.
* **State Performance:** Looked at the top five states by total sales.
* **Interactive Filters:** Added slicers for state, product category and year to explore different parts of the data.

## Tools and Skills

* Microsoft Excel
* Pivot Tables and Pivot Charts
* Data Filtering and Slicers
* Dashboard Design and Data Visualisation

## What I Learned

This project gave me practical experience in organising sales data, summarising it with pivot tables and presenting the results through charts. It also helped me understand how interactive filters can make a dashboard more useful when comparing products, locations and time periods.
